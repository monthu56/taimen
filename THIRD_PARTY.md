# Стороннее программное обеспечение

Этот репозиторий не содержит стороннего кода: скрипты в `tools/` и `deploy/`
используют только стандартную библиотеку Python. Сторонние зависимости каждого
компонента Taimen перечислены в файле `THIRD_PARTY.md` репозитория компонента
(для Python-компонентов его генерирует `tools/generate_third_party.py`).

Ниже — стороннее программное обеспечение, которое сборка использует, но не
распространяет: образы контейнеров, которые `compose.yml` загружает из реестров, и
инструменты сборки руководства. Каждое распространяется под собственной лицензией.

| Программа | Где используется | Лицензия |
|---|---|---|
| PostgreSQL (`postgres:16-alpine`) | базы данных сервисов | PostgreSQL License |
| MinIO (`minio/minio`) | хранилище содержимого артефактов | AGPL-3.0 |
| MinIO Client (`minio/mc`) | одноразовая настройка бакета | AGPL-3.0 |
| Caddy (`caddy:2-alpine`) | внешний контур и отдача руководства | Apache-2.0 |
| Keycloak (`quay.io/keycloak/keycloak`) | необязательный профиль `idp` | Apache-2.0 |
| MkDocs | сборка руководства `guide/` | BSD-2-Clause |
| Material for MkDocs | тема руководства `guide/` | MIT |

MinIO и MinIO Client работают как отдельные процессы в своих контейнерах и
взаимодействуют с платформой по сети (S3 API); код платформы с ними не связывается.
Вместо MinIO можно использовать любое S3-совместимое хранилище (`CP_S3_ENDPOINT_URL`).
